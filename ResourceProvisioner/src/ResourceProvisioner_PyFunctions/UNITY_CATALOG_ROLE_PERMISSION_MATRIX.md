# Unity Catalog Role Permission Matrix

This table maps workspace roles to Unity Catalog presets and merged permissions applied at catalog scope.

| Role | Preset | Applied Catalog Permissions |
| --- | --- | --- |
| Owner | ALL_PRIVILEGES | ALL_PRIVILEGES |
| Guest | DATA_READER | USE_CATALOG, BROWSE, USE_SCHEMA, EXECUTE, READ_VOLUME, SELECT |
| Admin | DATA_EDITOR | USE_CATALOG, CREATE_SCHEMA, BROWSE, APPLY_TAG, USE_SCHEMA, EXECUTE, READ_VOLUME, SELECT, MODIFY, WRITE_VOLUME, CREATE_FUNCTION, CREATE_MATERIALIZED_VIEW, CREATE_MODEL, CREATE_TABLE, CREATE_VOLUME |
| User | DATA_EDITOR | USE_CATALOG, CREATE_SCHEMA, BROWSE, APPLY_TAG, USE_SCHEMA, EXECUTE, READ_VOLUME, SELECT, MODIFY, WRITE_VOLUME, CREATE_FUNCTION, CREATE_MATERIALIZED_VIEW, CREATE_MODEL, CREATE_TABLE, CREATE_VOLUME |
