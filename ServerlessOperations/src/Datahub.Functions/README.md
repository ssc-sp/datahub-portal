# Datahub.Functions – Quick start (console mode)

Run the Azure Functions project locally in the console with Azure Functions Core Tools.

Prerequisites
- .NET SDK 9.0 or later
- Azure Functions Core Tools v4
- Azurite (for local Storage emulator) or an Azure Storage account


Start the Functions host
1) Open a terminal at the project folder:
- cd ServerlessOperations/src/Datahub.Functions

2) Start the host:
- `func host start`
